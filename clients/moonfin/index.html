Previews

Moonfin is a media client for Jellyfin and Emby servers, built with Flutter. A single shared codebase powers phones and tablets, Windows, macOS, and Linux, Android TV, Fire TV, and Apple TV, plus an installable web app, all with a navigation scheme tuned for touch, pointer, and remote input.

Beyond core playback, Moonfin supports a unified library that merges multiple Jellyfin and Emby servers into one browsable UI, offline downloads with automatic organization, ebook and audiobook reading, and retro game emulation with gamepad support and cross-device save states. A theme store with a built-in editor and OLED mode, Live TV with DVR, SyncPlay, and Seerr integration for discovery and requests round out the feature set. Web playback and the theme store sync are powered by the companion Moonbase server plugin.
