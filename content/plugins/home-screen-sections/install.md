1. Install the [File Transformation](https://github.com/IAmParadox27/jellyfin-plugin-file-transformation) and [Plugin Pages](https://github.com/IAmParadox27/jellyfin-plugin-pages) plugins first. Both are required.
2. Add `https://www.iamparadox.dev/jellyfin/plugins/manifest.json` as a plugin repository in **Dashboard → Plugins → Repositories**.
3. Install **Home Screen Sections** from the catalogue, then restart Jellyfin.
4. Open the hamburger menu on the user's homepage and select **Modular Home**.
5. Enable support and select the sections you want, then save.
6. Force-refresh the page (or app) to see the new home screen.
