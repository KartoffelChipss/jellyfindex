The Streamyfin Companion Plugin is a server-side plugin that centralizes configuration for the Streamyfin mobile app. It lets admins manage and lock playback, audio, subtitle, and swipe-gesture settings for every user from the Jellyfin dashboard instead of having to configure each device individually.

Besides the settings sync, it also enables adds customizable home screen sections, push notifications for new media, sessions, and playback events, and automatic SSO login for Seerr, plus integrations with Streamystats and Marlin search.
