1. Open **Jellyfin Dashboard** → **Plugins** → **Catalog**
2. Click the settings icon next to "Catalog" and **Add** a new repository with this URL:
    ```
    https://raw.githubusercontent.com/streamyfin/jellyfin-plugin-streamyfin/main/manifest.json
    ```
3. Go back to **Catalog**, search for "Streamyfin", and click **Install**
4. Restart Jellyfin to complete installation

Requires .NET 9 / Jellyfin 10.11 or newer.
