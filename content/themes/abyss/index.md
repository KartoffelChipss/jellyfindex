Abyss is a clean, minimal dark theme for Jellyfin built around frosted glass surfaces, refined typography, and smooth animations that re-skin nearly the entire interface.

It ships with one-click installers for Windows and Linux that configure your whole Jellyfin instance (CSS, dashboard theme, home section order, and Spotlight) in one step, alongside a lighter "Lite" mode that keeps the same look while reducing blur, shadows, and motion. Accent color and corner rounding can be customized via CSS variables.
