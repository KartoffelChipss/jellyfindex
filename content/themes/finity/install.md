**Complete theme:**

```css
@import url('https://cdn.jsdelivr.net/gh/prism2001/finity@main/complete/finity-complete.css');
```

**Minimal theme** (no backdrop gradient, no clickable episode titles in the season grid):

```css
@import url('https://cdn.jsdelivr.net/gh/prism2001/finity@main/minimal/finity-minimal.css');
```

Add to the **top** of your Jellyfin Custom CSS field. See the [README](https://github.com/prism2001/finity#readme) for display-setting prerequisites and customization variables.
