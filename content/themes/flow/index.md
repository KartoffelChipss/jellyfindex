Flow is a Plex-inspired theme for Jellyfin's web client, built on top of [scyfin](https://github.com/loof2736/scyfin).

Optional add-ons layer on top of the base theme: a collapsible drawer menu, a bigger logo for high-DPI displays, an episode grid borrowed from Ultrachromic, rounded cast/crew cards, and several color presets (orange, pink, rainbow, red, white).
