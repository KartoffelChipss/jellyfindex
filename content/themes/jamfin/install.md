**Complete theme** (base + all optional modules):

```css
@import url('https://cdn.jsdelivr.net/gh/JamsRepos/Jamfin@latest/theme/complete.css');
```

**Base theme only:**

```css
@import url('https://cdn.jsdelivr.net/gh/JamsRepos/Jamfin@latest/theme/base.css');
```

Paste into the **Custom CSS code** field under **Dashboard → General** (applies server-wide), or under your own **Display** settings with "Disable server-provided custom CSS code" enabled (applies to you only). See the [modules folder](https://github.com/JamsRepos/Jamfin/tree/main/theme/modules) for optional add-ons.
