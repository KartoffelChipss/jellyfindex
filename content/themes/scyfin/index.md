scyfin is a custom CSS theme for Jellyfin with support for backdrops and several accent-color themes, including Seafoam, Coral, and Snow.

Optional add-ons can disable the static left drawer, disable backdrops on navigation pages, or switch the "Identify" search results to a list view. See the [README](https://github.com/loof2736/scyfin#readme) for the full list.
